# Data contoh

Seluruh data dalam folder ini dibuat untuk demonstrasi teknis. Nilai harga,
jarak, waktu tempuh, frekuensi, nama sumber, dan struktur jaringan tidak boleh
ditafsirkan sebagai data resmi atau gambaran kondisi aktual.

- `price-analysis.json`: payload siap kirim ke endpoint analisis harga.
- `network-analysis.json`: payload siap kirim ke endpoint analisis jaringan.
- `prices.csv`: contoh struktur impor observasi harga.
- `routes.csv`: contoh struktur impor rute distribusi.

Tidak ada koordinat rinci, identitas individu, atau kredensial pada data contoh.
